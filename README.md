# ProTask Workspace - Spring Boot Backend

RESTful API backend for Task Management application connected to MySQL database.

## Tech Stack
- Java 17+
- Spring Boot & Spring Data JPA
- MySQL
- Lombok

## Endpoints
- `GET /api/tasks` - Fetch all tasks
- `POST /api/tasks` - Create a task
- `PUT /api/tasks/{id}` - Update task status
- `DELETE /api/tasks/{id}` - Delete a task
